This project explores the use of Deep Learning for automated human sperm morphology classification using the DenseNet169 Convolutional Neural Network (CNN) architecture.

The objective of this research is to assist sperm morphology analysis by creating a system capable of recognizing and classifying sperm cells based on their visual characteristics.

Manual sperm morphology evaluation is often difficult because many sperm categories appear visually similar and require significant expertise and time to classify consistently. This project investigates whether computer vision techniques can support this process by learning visual patterns directly from microscopic images.
